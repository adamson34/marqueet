MARQUEET
========

1. Plug the Raspberry Pi into your TV or monitor, your router (network
   cable), and power.
2. The first start takes about 10 minutes while it installs. Then the ticker
   appears with a QR code.
3. Scan the QR code with your phone (or open http://marqueet.local:7878),
   enter the 6-digit code from the screen, and choose a password.

Forgot your password? Put this card in any computer and create an empty
file named "reset-password" next to this one. Put the card back in the Pi
and start it: the setup code appears on the screen again.

Updates install automatically.

More help: https://github.com/adamson34/marqueet
